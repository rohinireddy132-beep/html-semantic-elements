Semantic HTML5 Elements

Understanding and using semantic HTML for better web accessibility and SEO

What are Semantic HTML Elements?

Published on September 1, 2026

Semantic HTML elements are elements with meaning. They clearly describe their meaning to both the browser and the developer.

Benefits of Using Semantic HTML

  • Improves accessibility for screen readers
  • Enhances SEO performance
  • Makes code more readable and maintainable
  • Provides better semantic structure

Written by Web Developer | Last updated: September 1, 2026

Common Semantic Elements

<header> Element

Represents a container for introductory content or a set of navigational links. Used for site headers, article headers, etc.

<header><h1>Page Title</h1></header>

<nav> Element

Defines a set of navigation links. Helps screen readers identify the navigation section of a page.

<nav><a href="#">Link</a></nav>

<main> Element

Specifies the main content of a document. There should be only one <main> element per page.

<main><!-- Page content --></main>

<article> Element

Represents self-contained, independent content. Perfect for blog posts, news articles, and forum posts.

<article><h2>Article Title</h2></article>

<section> Element

Defines a thematic grouping of content. Use it to organize related content within an article or page.

<section><h2>Section Title</h2></section>

<aside> Element

Represents content aside from the main content, like sidebars, callout boxes, or related information.

<aside><p>Sidebar content</p></aside>

<footer> Element

Represents footer content for a page, article, or section. Often contains copyright info, links, or metadata.

<footer><p>© 2026</p></footer>
